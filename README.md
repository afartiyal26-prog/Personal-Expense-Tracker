# Personal Expense Tracker

A simple and user-friendly web application to track and manage personal expenses.

## Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Calculate total spending
- Track total transactions
- View expenses by category
- Save expenses using browser Local Storage
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Project Structure

Personal-Expense-Tracker/
│
├── index.html
├── style.css
└── script.js

## How It Works

Users can enter an expense description, amount, category, and date. The application calculates total spending and displays expenses by category. Data is stored in the browser's Local Storage, so expenses remain available after refreshing the page.
